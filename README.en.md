# Hero App — Front end

[Versão em português](README.md)

The Hero App web interface, built with React 19, TypeScript, and Vite. It uses client-side routing, forms, and REST API integration.

## Stack

- React 19 and TypeScript
- Vite
- React Router DOM
- Axios
- Tailwind CSS 4 and DaisyUI
- React Hook Form, React Hot Toast, and React Icons
- ESLint

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```

The matching backend is available at [hero-app-back](https://github.com/leoo1992/hero-app-back). Configure the API URL for each environment; never place real credentials in frontend code.
