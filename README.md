# Hero App — Front-end

[English version](README.en.md)

Interface web do Hero App, desenvolvida com React 19, TypeScript e Vite. O projeto utiliza roteamento client-side, formulários e integração com API REST.

## Stack

- React 19 e TypeScript
- Vite
- React Router DOM
- Axios
- Tailwind CSS 4 e DaisyUI
- React Hook Form, React Hot Toast e React Icons
- ESLint

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```

O backend correspondente está em [hero-app-back](https://github.com/leoo1992/hero-app-back). Configure a URL da API conforme o ambiente; não inclua credenciais reais no frontend.
